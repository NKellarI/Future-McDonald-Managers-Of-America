Smart Shopper Design Artifacts

Smart Shopper Features

Prioritized features based on user needs and stories.

MVP means Minimum Viable Product. The bold features are the most important features for the first working version of Smart Shopper.

Priority Feature Description MVP
1 Shopping List Management Create, view, edit, and remove grocery items. Yes
2 Store Price Comparison Compare grocery item prices across participating stores. Yes
3 Estimated Store Totals Calculate the estimated cost of the entire list at each store. Yes
4 Quantity Support Allow shoppers to specify how many of each item they need. Yes
5 Clear Comparison Results Display item prices, store totals, and the lowest-cost option clearly. Yes
6 Store Selection Allow users to select the stores they want to compare. Yes
7 Savings Calculation Show the estimated dollar difference between store totals. Yes
8 Saved Shopping Lists Save, reopen, and reuse shopping lists. Yes
9 Item Search Search for grocery products when creating a list. No
10 Item Categories Organize groceries into categories such as dairy, produce, and meat. No
11 Price Update Information Show when store prices were last updated. No
12 Price History Allow users to review historical prices for grocery products. No
13 User Accounts Allow users to save lists and preferences across devices. No
14 Notifications Notify users about relevant price changes or saved-list updates. No
