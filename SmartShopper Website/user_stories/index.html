Smart Shopper Design Artifacts

User Stories

User needs and requirements for Smart Shopper.

Shopping List Management

  • As a grocery shopper, I want to create a shopping list so that I can organize the items I need.
  • As a grocery shopper, I want to add items to my list so that I can keep track of groceries.
  • As a grocery shopper, I want to remove items so that my list stays accurate.
  • As a grocery shopper, I want to edit item quantities so that my estimated costs are accurate.
  • As a grocery shopper, I want to organize items into categories so that I can find them easily.

Store Price Comparison

  • As a shopper, I want to compare an item's price across stores so that I can find the lowest price.
  • As a shopper, I want to select which stores to compare so that I can view relevant options.
  • As a shopper, I want to see the cheapest store for an item so that I can make an informed decision.
  • As a shopper, I want to view prices side by side so that comparisons are easy.
  • As a shopper, I want to see when prices were updated so that I can judge how current they are.

Estimated Store Totals

  • As a shopper, I want to see the estimated total for my entire list at each store so that I can compare overall costs.
  • As a shopper, I want totals to update when I edit my list so that the estimate stays current.
  • As a shopper, I want quantities included in the total so that the estimate reflects what I plan to buy.
  • As a shopper, I want to compare complete grocery baskets so that I can choose an affordable store.
  • As a shopper, I want to see the difference between store totals so that I understand potential savings.

Saved Shopping Lists

  • As a shopper, I want to save a shopping list so that I can use it again later.
  • As a shopper, I want to name saved lists so that I can identify them easily.
  • As a shopper, I want to reopen a saved list so that I do not have to recreate it.
  • As a shopper, I want to edit saved lists so that I can adjust them for future trips.
  • As a shopper, I want to remove old lists so that my saved lists remain organized.

Search and Comparison Results

  • As a shopper, I want to search for grocery items so that I can add products quickly.
  • As a shopper, I want to see clear store names and prices so that I can understand the results.
  • As a shopper, I want to see which store has the lowest total so that I can make a cost-effective choice.
  • As a shopper, I want to know that prices are estimates so that I understand they may change in store.
  • As a shopper, I want to see potential savings so that I can decide whether comparing stores is worthwhile.
